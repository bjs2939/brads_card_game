# Battle playlist

Drop MP3, OGG, WAV, M4A, or FLAC tracks here. The game plays its original battle theme first, then the files in this folder in filename order and repeats the playlist. Use filenames such as 01-opening.mp3 and 02-siege.ogg to set the order.

Restart the local preview after adding tracks if the playlist does not refresh. Rebuild and publish the game to include new tracks on the public site.
