# brads_card_game
Full Stack Web-based version of a custom card game created by two brothers. Built with React, TypeScript, Node.js, and SQL for online gameplay and data tracking.

## v0.2 playtest

- Feedback is available in the main menu and at the bottom of a match. Review the draft before opening GitHub. GitHub sign-in and a final **Submit new issue** click are required. Public issues should never contain contact information, secrets, or unreviewed screenshots.
- Optional feedback context contains game version and coarse match counts. No hands, card identities, raw logs, email addresses, or screenshots are collected by the game. Attach a reviewed screenshot in GitHub if useful.
- Maintainers can triage feedback from the repository's **Issues** tab. The bracketed category in the title helps identify reports. Private return-email handling, automated issue creation and labels require a separately approved backend. GitHub Pages has no server-side runtime.
- Sandbox is a **VS Computer** difficulty with a defensive opponent that never attacks. **Training Grounds** is a separate main-menu mode. Its Lab opens during your turn and lets you add or remove cards in either hand or battlefield. Move a card already in play by removing it before adding it elsewhere.
- Match History keeps up to 12 recent matches in this browser. Turn Timer starts off and is available in match settings. Campaign is a menu placeholder.
- Run `npm run dev` for local play, or `npm run build` for a production build.
